# Vaelor Vel'tharn

## ► Informações Gerais
- **Povo:** [[Elfos do Breu]]
- **Família:** irmão de [[Nhyra Vel'tharn]]; casado com [[Aelindra Caelum]]; pai de [[Bri'kan Caelum]]

## ► História
Uma geração antes do fim de [[Aeltharis]], **subiu das cavernas** para se casar com a rainha das estrelas e reinar ao lado dela — um casamento para selar a paz entre os dois povos. *A paz durou menos que o casamento, mas deixou um filho.*

Morreu no sacrifício das coroas. → [[Queda de Aeltharis]]
